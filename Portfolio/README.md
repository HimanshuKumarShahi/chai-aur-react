# Himanshu Kumar – Portfolio

A modern, responsive developer portfolio built with **React** and **Tailwind CSS v4.1**.  
This site showcases my projects, skills, and contact information as a BCA student and aspiring full‑stack developer.

---

## 🔥 Features

- **Modern UI** with dark theme and orange highlights
- **Responsive layout** for mobile, tablet, and desktop
- **Protected profile image** (right‑click/drag disabled)
- **Smooth background effects** (radial glows, blurred shapes, subtle animations)
- **Structured sections**
  - Hero (intro + CTA buttons)
  - Why Choose Me
  - Skills with animated progress bars & “Show More” toggle
  - About page (Who I Am, skills, experience, education)
  - Projects page (list of selected work)
  - Contact page (social links, resume download, mailto form)
- **Navbar & Footer**
  - Icon‑based navigation (Home, About, Projects, Contact)
  - Social icons and quick links in footer
- **Contact form with validation**
  - Name, email, and message checks
  - Opens user’s email client via `mailto:` with pre‑filled content
  - Clears form fields after sending

---

## 🛠 Tech Stack

- **Frontend:** React (Vite or CRA, depending on setup)
- **Styling:** Tailwind CSS v4.1
- **Icons:** React Icons (`react-icons`)
- **Routing:** `react-router-dom`
